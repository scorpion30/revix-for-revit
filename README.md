# ReviX for Revit

ReviX is an add-in for Autodesk Revit 2024, 2025, 2026 and 2027 (Windows): rooms and finishes, door numbering, sheets, parameters, coordination, and AI Connect / AI Chat.

**Website:** https://scorpion30.github.io/revix-for-revit/

**Download:** [Revix-Setup.exe (latest)](https://github.com/scorpion30/revix-for-revit/releases/latest/download/Revix-Setup.exe)

1. Close Revit and run the installer (no admin rights needed).
2. Open Revit and choose **Always Load** when asked.
3. The **ReviX** tab appears on the ribbon.

Feedback: use the **Feedback** button on the ReviX tab inside Revit.
