Install

Download

Get Revix-Setup.exe from this page. Close Revit before you run it.

Run the installer

Open Revit

FAQ

Questions, answered.

Which Revit versions are supported?

Revit 2024, 2025, 2026 and 2027 on Windows. One installer covers all of them; install Revit 2027 later and just run the installer again.

Do I need admin rights?

No. ReviX installs into your own user folders, so it works on locked-down office PCs without IT.

Is my model sent anywhere?

No. ReviX works inside Revit on your computer. With AI Connect, your own AI app talks to Revit locally; with AI Chat, requests go only to the AI provider whose key you entered.

Can I undo what a tool did?

Yes. Every tool writes its changes as a single Revit transaction — press Ctrl+Z once to undo it.

How do I update?

Download the latest installer from this page and run it over the old one. Your settings are kept.

How do I uninstall?

Windows Settings → Apps → Installed apps → Revix → Uninstall.

Found a bug or have an idea?

Click Feedback on the ReviX tab inside Revit. It goes straight to the developer, and replies show up right there in Revit.

Why are some buttons grey?

Those tools are still being refined. They light up in a future version once they're reliable enough to trust with your project.
